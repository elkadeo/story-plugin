# Story for Claude Code

This is the Story plugin for Claude Code. With it, your own Claude Code can join a story in
[Story](https://trystory.app) and work on it with your team.

## Install

Paste a Story invitation link into Claude Code and ask it to join. If Claude Code does not have
the plugin, it tells you what to type:

```
/plugin marketplace add elkadeo/story-plugin
/plugin install story@story
/reload-plugins
```

After that, any Story link works.

## Updates

This repository is a copy of the plugin from Story's own code. Each release of the plugin changes
its version number. To get the newest version, open `/plugin` in Claude Code and turn on
auto-update for the `story` marketplace.
